# Projeto 8: Criador de Orçamento e Controle Financeiro Simples

### Prompt principal

```
Você é um consultor financeiro especializado em orçamento doméstico simples e realista, com foco em pessoas que estão começando a organizar a vida financeira.

Crie um controle financeiro e orçamento mensal com base nas informações abaixo:

- Renda mensal líquida: R$ [valor]
- Gastos fixos (moradia, contas, transporte, etc.): [liste ou diga o valor aproximado]
- Gastos variáveis (alimentação, lazer, compras, etc.): [liste ou diga o valor aproximado]
- Objetivo principal: [ex: sair do vermelho / guardar dinheiro / quitar dívidas / ter reserva de emergência / controlar melhor os gastos]
- Valor que gostaria de guardar por mês: R$ [valor] (se tiver)
- Situação atual: [ex: estou no vermelho / sobra um pouco / não sei para onde vai o dinheiro]
- Número de pessoas na casa: [ex: moro sozinho / casal / família com filhos]

Organize a resposta da seguinte forma:

1. **Diagnóstico rápido** da situação financeira
2. **Orçamento mensal sugerido** (dividido por categorias, com valores recomendados)
3. **Meta de economia** realista
4. **Lista de cortes ou ajustes** possíveis (práticos e sem radicalismo)
5. **Modelo simples de controle semanal** (para eu acompanhar os gastos)
6. **Dicas práticas** para não estourar o orçamento

Use linguagem simples, direta e sem julgamento. Seja realista e motivador.
```


### Versão curta:

```
Crie um orçamento mensal simples e realista para mim.

Renda: R$ [valor]
Gastos fixos aproximados: R$ [valor]
Objetivo: [ex: guardar dinheiro / organizar melhor / sair do vermelho]

Faça:
1. Divisão sugerida do orçamento por categorias
2. Quanto eu consigo guardar por mês
3. Onde posso cortar gastos sem sofrer muito
4. Um modelo simples para eu controlar meus gastos toda semana

Linguagem clara e prática.
```


### Versão focada em quem está no vermelho:

```
Estou com dificuldades financeiras e preciso organizar minha vida.

Renda mensal: R$ [valor]
Gastos atuais: [descreva de forma geral]
Dívidas: [se tiver, diga aproximadamente]

Me ajude com:
1. Um diagnóstico sincero da situação
2. Um orçamento de guerra (prioridades)
3. O que cortar primeiro
4. Como começar a guardar mesmo que seja pouco
5. Um plano simples para os próximos 30 dias

Seja direto, realista e sem julgamento.
```


### Versão para criar uma planilha mental (ou copiar para Excel)

```
Crie um modelo de controle financeiro mensal simples que eu possa copiar para uma planilha.

Inclua:
- Categorias de receita
- Categorias de despesas (fixos e variáveis)
- Coluna de valor previsto
- Coluna de valor real
- Coluna de diferença
- Meta de economia

Depois explique como eu devo preencher e acompanhar toda semana.
```

### Dica de uso
Depois de gerar, você pode pedir:
- “Ajuste o orçamento para eu guardar R$ 300 por mês”
- “Deixe mais apertado”
- “Inclua uma categoria para lazer”
- “Faça uma versão para quem ganha por semana”
- “Me dê um plano para os próximos 3 meses”
